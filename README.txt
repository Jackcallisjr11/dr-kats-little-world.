DR. KAT'S LITTLE WORLD — FINAL RELEASE
======================================

This is the consolidated final release package based on the latest working
Prototype 23 build. It includes the cumulative game features and fixes.

INCLUDED
- One connected island with the five agreed zones and free exploration
- Dr. Kat and Jack characters, movement and walking animation
- Garden, riverside, forest and island interactions
- Gentle study check-in and optional MCQ/rewards
- Profile, bag, shop, settings and local save
- Manual JSON export/import for moving progress between devices
- Optional ambient sound, rain, fireflies and sky moods
- Mobile touch controls, responsive layout and fullscreen support
- Installable web-app metadata and offline app-shell caching

PUBLISH / UPDATE GITHUB PAGES
1. Extract this ZIP.
2. Open the existing public repository:
   https://github.com/jackcallisjr11/dr-kats-little-world
3. Upload and replace these five files in the repository root:
   index.html, manifest.webmanifest, icon.svg, sw.js, README.txt
4. Commit the changes to the main branch.
5. Wait for the GitHub Pages deployment workflow to show a green success tick.
6. Open the published site:
   https://jackcallisjr11.github.io/dr-kats-little-world/

IMPORTANT NOTES
- This package is prepared locally; it is not automatically uploaded or published.
- Progress is stored in each device's browser. There is no automatic cloud sync.
  Use Settings -> Export backup on one device and Import backup on the other.
- The character figures use CSS-based prototype artwork and animation. A final
  bespoke hand-drawn sprite-art set has not been integrated.
- Test the live page on both devices before sharing widely. If an older build
  appears, refresh the page or clear the site's browser cache.
